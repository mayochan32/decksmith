# DeckSmith v0.9.0

各ページで伝える内容に合わせて構図・図解・画像を選ぶ制作手順を改善しました。プレゼン資料に加え、ページごとの目的と使ったテクニックを説明するMarkdownを標準で納品します。

## 配布パッケージ更新 — 2026-10-18

通常版・Windows PORTABLE版の添付ZIPに、制作開始用の `setting/decksmith.yaml` を追加しました。通常版は `renderer: libreoffice`、PORTABLE版は `renderer: powerpoint` を設定済みです。PPTXのみの場合は `renderer: none` に変更してください。

既存の設定を使っている方は上書きせず、別の場所へ展開してください。バージョンはv0.9.0を維持し、ZIPとSHA256SUMS.txtを更新しました。公開済みタグは移動しないため、この追加は更新された添付ZIPを利用してください。

## 主な変更

- 聞き手の問い、主張、要素の関係を整理してから配置を決定。大見出しと二列の繰り返しに固定せず、数値・比較・人物・概念図など内容に応じた主役を選びます。
- 文字と図形の大きさ、行間、余白、軸見出し、成果の強調を確認するガイドを追加。明示された要素群のバランスを測定し、視覚レビューを補助します。意図した重なりや非対称は許容します。
- 画像の余白・透過・模様の密度を利用し、文字と画像を自然に組み合わせる手順を追加しました。
- 最終PPTXと同じ場所へ `.design-notes.md` を作成。各ページの目的、伝えたいこと、テクニックを使った箇所と狙い、想定する読み順を説明します。制作を担当するAIの納品工程で作成し、描画用buildコマンド単体では生成しません。
- Codex／ChatGPTデスクトップ、Claude Code向けのローカルプラグイン登録情報・カタログと、導入ガイドを整備。既存の作業フォルダーへのSkill登録も利用できます。
- 通常版ZIPの作成、任意のブラウザー試験用ZIPの作成、配布物だけでPPTX・PDF・PNGを確認するスモークテストを追加しました。

## ダウンロード

- **decksmith-v0.9.0.zip**：通常版。各AIツール共通のSkillと登録情報・導入処理を同梱します。Python／Node.js等の実行環境は別途必要です。
- **decksmith-v0.9.0-portable-win-x64.zip**：Windows x64用PORTABLE版。Python／Node.jsと描画用依存パッケージを同梱します。PNG・PDFの出力にはWindowsデスクトップ版PowerPointが必要です。
- **SHA256SUMS.txt**：上記2ファイルのSHA-256チェックサム。

## 確認状況

119件のテストのうち118件が成功し、Windows実機専用の1件は未実施です。通常版の単独生成、LibreOfficeによるPDF・PNG出力、PORTABLE版ZIPの内容と同梱JavaScriptの読込、版番号と配布内容の一致を確認しました。

Windows上でのPORTABLE版・PowerPointの動作、各クライアント画面からのプラグイン導入、ブラウザー実行は今回の検証に含みません。ブラウザー版は実験扱いで、今回の配布ファイルには含めていません。フォントは埋め込まれないため、閲覧先の環境で見た目が変わる場合があります。

詳細は[配布検証](validation-v0.9.0.md)を参照してください。
