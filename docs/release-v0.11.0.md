# DeckSmith v0.11.0 — 既存PPTXのスタイル変換・第一段階

既存PPTXの文章と配置を保持して、指定したstyle.yamlの書式を適用するモード①を追加した。元ファイルを複製し、許可した書式属性だけを変更する。新規資料の再生成による配置の作り直しは行わない。

## 追加した機能

- `restyle_deck.py inspect`：元資料のページ順、文字、要素ID、座標、保持制約を読み、AIが完成させる変更計画を作る。
- `restyle_deck.py apply`：背景、図形の塗り・線色、文字色・書体・サイズ・太字・斜体を変更する。
- 文字・空白・明示改行、座標、寸法、重なり順、グループ、切り抜き、ノート、図表等を比較する保持検査。
- 変更前後の全ページプレビュー、任意のPDF出力、変更レポート、入力と出力の指紋を保存する。
- 適用できない指定と部分適用を理由付きで記録し、未対応指定が残る試作を完成品と区別する。
- 画像を含む背景や図形の塗りを単色で覆う変更を拒否する。継承された背景も確認する。
- Windows PORTABLE版の`inspect-source` / `restyle`コマンドと、共通の`review`による比較レビュー。

スタイルの意味はAIが解釈し、処理側は変更できる属性を制限する。任意のスタイル表現をすべて変更できるという意味ではない。書体や文字サイズの変更による折り返し・はみ出しは、元資料との実際の比較が必要。

## 今回の範囲

PPTX入力・モード①を実装。PDF/PPT入力、モード②（文章改善・配置固定）、モード③（全体再設計）は未実装。画像・表・グラフ・マスター内部のスタイル変更も対象外で、元の部品を保持する。デジタル署名付き・Strict OOXMLは未対応。

通常版のローカルZIPを作成した。GitHubへのpush、タグ付け、Release公開、Windows PORTABLE版の新しいZIP作成は行っていない。

詳しい手順は[利用ガイド](../USER_GUIDE.md#25-既存pptxのスタイル変換モード①)、検証範囲は[検証記録](validation-v0.11.0.md)を参照。
