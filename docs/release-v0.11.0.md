# DeckSmith v0.11.0

v0.10.0以降の改善をまとめた公開版です。既存資料の改善、新規の編集可能な表・グラフ、図の接続と読み順、文字の見え方の検査を追加しました。開発中の未公開版をこのリリースへ統合し、配布ZIP・VERSION・各ホストの登録情報をv0.11.0に揃えています。

## 主な変更

- **既存PPTX・PDFの改善**：①文章・配置を保持したスタイル変更、②配置を固定した文章改善、③文章・配置・ページ構成の再設計。変更前後のプレビューと内容の保持を確認します。PDFは抽出した文字を編集可能に復元し、図表は画像として保持します。
- **編集可能な表・グラフ**：新規の表、横棒・縦棒・折れ線グラフと編集用データに対応。表は格子・横罫線のみ・罫線なしを選べます。セルや棒グラフの一部を強調しても、全条件・全数値と0を保持して照合します。
- **関係図と条件文**：接続先を参照して経路を組み立て、条件文を対応する線の近くへ配置します。主な流れ、例外、戻り先、二つの終点などを原稿に合わせて整理し、線の交差・接触・重なりも確認します。
- **文字の見え方**：収まり、一字だけの折り返し、線と文字の交差、文字同士の重なり、図形に隠れた文字、既知の背景との対比を検査の手がかりにします。
- **Mac・Windowsの書体名確認**：使用する書体名がその端末にあるか調べられます。書体の導入・置換・埋め込みは行いません。
- **資料全体の構成**：見出しと図表の強弱を結び付け、同じ説明の反復を見直します。代表ページの案を画像で比較し、内容に合う配置を選びます。制作指示を読者向けの説明へ直す基準も具体化しました。

## 検証範囲

自動検証267件は259成功・8スキップ・失敗0。通常版とWindowsポータブル版の内容をソースと照合し、通常版から再生成した全6ページの画像が確認済み資料と一致しました。詳しくは[検証記録](validation-v0.11.0.md)を参照してください。Windows・Macの実際のVSCode、PowerPoint本体での表示・編集・再保存、別端末のフォント置換の確認は後工程です。

検査の成功だけで見た目の品質や意味の正しさを保証しません。文字の字幅・収まりは推定であり、画像背景・回転・半透明の重なり・グラフ内部ラベルの位置など、未測定の範囲は実画像で確認します。PPTX上で枠をドラッグした際の線の自動追従は対象外です。
