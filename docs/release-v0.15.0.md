# v0.15.0 編集可能な表・グラフと元データの照合

ローカルの未公開改修版。v0.14.0の制作手順・比較機能に加え、共通描画エンジンを変更した。Gitタグ・push・公開・既存VSCode環境へのインストールは行っていない。

## 共通部分への変更

- 新規のネイティブ表を追加。列幅・行高・セルの強調を指定し、全行・全列・空セルを編集可能なまま保持する。自動的にページを追加しない。
- 新規の横棒・縦棒・折れ線グラフを追加。系列と項目、数値、単位、凡例、値ラベル、表示桁、軸範囲を扱い、編集用ブックをPPTX内へ埋め込む。
- 元データをstructureのevidenceへ記録し、原稿由来の独立したcontent-contractへ固定する。sceneから基準を逆生成しない。丸めた表示が同じでも元の値の変更は検出する。
- 出力検査を拡張。表のセル単位の内容と行列・寸法、グラフのキャッシュとブック参照、実際のブック内データ、単位・表示形式・明示軸を照合する。棒グラフは0を含む軸とし、全値を範囲内に保持する。
- 日本語の単位が横倒しにならないよう指定し、横棒の項目を上から原稿順で読めるようにした。
- 制作ガイドから、数値・条件の整理と表現選択の手順へ接続。比較すべき量・単位・条件を確かめ、内容に合う表・グラフ・写真・文章を選ぶ。全ページを図表化するルールは追加していない。

## 生成ライブラリとの接続で見つかった問題

使用中のPptxGenJS 4.0.1では、0がグラフのキャッシュにある一方で編集用ブックでは空欄になるケースと、ブック内の表範囲の末尾に不要なアポストロフィが付くケースを確認した。

新規の生成候補ファイルだけを対象に、入力値が0で、生成セルが空の箇所を0へ戻す。既知の末尾記号だけを除去し、その後でキャッシュ・元データ・ブックを照合する。他の不一致を入力値で上書きして隠さない。描画・最終ハッシュ・レビューより前の処理であり、既存の利用者資料には適用しない。追加の外部サービスや依存パッケージは不要。

## 別題材での表示確認

相対性理論とは別に、地域イベントの受付を題材とした4ページを制作。すべて検証用の架空データと画面上に明示している。

1. 来場者数4カテゴリを縦棒で比較。
2. 受付待ち時間を3カテゴリ・2系列の横棒で比較。
3. 待ち人数の全5時点・2系列を折れ線で表示。両系列の開始時点の0もブックに保持。
4. 運営条件を6行・3列で照合し、例外対応を強調。

3回描画。初稿で見つかった単位の横倒しと横棒の項目順を共通処理で修正。修正後の3グラフを個別に確認し、表は確認済み初稿と画像指紋が一致。最終版は発表者ノートを説明用の文章に整理し、全PNGが確認済み版と一致。元データの数値を変えて見た目を整えることはしていない。

成果物：`artifacts/native-evidence-20261121/output/native-evidence-003.pptx`、同名PDFと設計説明。これは機能と表示の適用例であり、旧版との独立した品質比較や、別のAIによる再現性の証明ではない。

## 確認した範囲

- 全体テスト199件、失敗なし、Windows等の環境依存9件skip。新規18件では入力検証・原稿からの独立データ保持・百分率・負数・0・全6行の保持・キャッシュ改変・ブック改変の検出を確認。描画調整後に新規18件を再実行。
- スキルquick_validate、版番号整合、git diff --checkを確認。
- LibreOfficeでPPTXからPDF・全ページPNGへ描画。表・グラフは画像への置換ではない。
- Windows版PowerPoint自体での編集・再保存、未知の依頼でのデザイン品質の安定性は未検証。自動検査の合格を美的品質や理解度の実証とは扱わない。

## 対応範囲

既存のtext/shape/path/image、既存資料の3変換モードは維持。新規表のセル結合や複雑なセル内リッチテキスト、積み上げ・円・複合軸などのグラフは未対応。対応外の要件を黙って別の形式へ変換しない。
