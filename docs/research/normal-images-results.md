# 画像量normalと自然な重ね方の比較

2026-10-11。ユーザーは画像量「普通」の結果を確認したいと指定。また、網点の上へ文字を置くための紙色の長方形が、貼り付けた四角に見えると指摘した。

## 適用

直前の相対性理論6ページを基準とし、制作設定をimages.amount=lessからnormalへ変更。原稿、structure、独立した内容基準、内容変更記録は同一のまま。normalを固定枚数にせず、今回は次の4ページで画像を使った。

| ページ | 画像の役割と変更 |
| --- | --- |
| 01 | 左・下へ点が疎らになる透過網点球を新規生成。下段の主張を覆っていた長方形を撤去 |
| 02 | 宇宙船と光の流れを描いた透過素材を新規生成。数値と単位を中央の余白へ直接重ね、長方形の覆いを撤去 |
| 03 | 双子の再会を表すイラストを新規生成。人物とラベルを対応させ、時間差の結果を具体化。年齢差は概念表現であり実測値ではない |
| 06 | GPS衛星と地上の利用場面を新規生成。二要因から時計補正への編集可能な図は保持 |

04の時空図・05の重力の比喩図は、編集可能な図が説明に適するため維持。画像の枚数や、今回選んだページ構成をプラグイン全体の固定規則にはしていない。

## 共通の制作ガイド

`references/image-assets.md`へ、自然に重ねたい場合は素材の余白・透過・模様の密度を先に設計し、背景色の長方形で隠すことを最初の対処にしない判断を追加。実際のスライド背景で画像境界と文字の干渉を確認する。意味を持つ囲み・帯は利用可能とし、長方形を一律禁止しない。

## 確認

- 組み込み画像生成で4素材を作成し、光速素材のみ1回調整。外部サービス・Web検索なし。生成結果を制作フォルダーのassetsへ保存。
- 全素材にRGBA透過があることを確認。生成画像の単体表示だけで判断せず、PPTX描画後の背景上で確認した。
- 2回生成。初稿の変更4ページを個別に確認し、光速の装飾にかかった不要な補助英字と、GPSの画像下の余白を調整。最終02・06を再確認し、01・03は確認済み初稿と画素一致。04・05は前回と画素一致。全6ページの同縮尺一覧も確認。
- 元原稿・内容基準の同一性、全6節の発表者ノート保持、生成文字の保持を確認。review_deckはpassedだが、これは成果物一致とレビュー網羅性であり理解度の自動評価ではない。
