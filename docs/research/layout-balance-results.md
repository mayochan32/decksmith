# 文字と図形のバランス：実装と適用例

2026-10-11。重なりを禁止せず、文字と図形の寸法・位置・余白を同時に設計する方針を追加した。開発ブランチ上の検証であり、mainへのマージは行っていない。

## 組み込み先

- [layout-balance.md](../../skills/decksmith/references/layout-balance.md)：同格要素の特定、文字と図形の同時設計、帯の視覚的重量、実際の字面の確認。design-planとquality-gatesから参照する。
- [layout_balance.py](../../skills/decksmith/scripts/layout_balance.py)：設計者が宣言したshape/labelの組だけを測定する。文字サイズ・図形寸法・比率・文字枠の中心・余白・間隔に資料固有の範囲を指定する。重なりの自動禁止、図形の自動移動は行わない。
- [design_quality.py](../../skills/decksmith/scripts/design_quality.py)：宣言の参照と範囲を検証し、design-checks.jsonに値と警告を保存。既存の視覚レビューへ引き継ぐ。
- [再現用入力](../../benchmarks/layout-balance-pilot/README.md)：図の座標はこの作例専用。本体のレイアウトプリセットではない。

## 4ページの比較

1. 交差を残す：四つの領域のカプセルと三本の帯を保持。帯の厚みとラベルの比率を調整し、領域名の余白を確保。
2. 上下に分ける：四領域を短いパネルへまとめ、その下に共通基盤を配置。関係の示し方を比較する別案。
3. カプセルを整える：幅440px・高さ240px、38pxの文字、等しい間隔・文字枠中心。最初の白塗りを保持。
4. パネルへ組み直す：幅440px・高さ184pxへ小さくし、角丸を抑える。文字サイズと先頭の強調を保持。

参照画像の全ラベルを保持。画像だけでは元PPTXの書体・文字枠・座標は確定できないため、忠実な復元や元図の数値測定とは称さない。「四領域と三つの共通基盤」は作例上の仮定。上下配置では交差による直接的な対応表示が弱くなるため、意味と好みを利用者が比較する対象として残す。
