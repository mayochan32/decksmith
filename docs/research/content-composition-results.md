# 内容に応じた構図の選択と、資料全体の反復の見直し

2026-10-11。前回の朱赤・網点版は、ページ単位では文字や余白が整っていたが、上部の巨大見出しと下部2領域の骨格が多く、ユーザーから単調と指摘された。色・装飾・カタログ名の違いを、構図の違いと取り違えた。

## 原因と変更

描画エンジンに2列や上部見出しを強制するコードはない。今回の制作では全ページのfocal_elementをtitleに置き、headingの最低サイズを90pxへ揃えていた。主張の強さを字の大きさへ狭く解釈し、関係図や比較の組自体が主役になる設計と、資料全体の反復レビューが不足していた。

- SKILL.mdの設計段階からcomposition-design.mdへ接続。内容の関係、視覚の主役、骨格と読み順の順で考える。
- design-plan.mdの固定的に見える96pxやtitleの例を外し、最低サイズを判読性の下限として説明。主役は図・比較・数値も選べる。
- layout-balance.mdは文字による主張の強さと、図による主張の読みやすさを区別。太字を弱める一律ルールにはしていない。
- communication-design.mdから構図の選択へ接続。quality-gates.mdに同縮尺の全ページ一覧による反復確認を追加。
- 同じ骨格が理解を助ける反復は残す。構図の固定カタログ、使用回数上限、多様性の点数、自動配置は追加していない。

## 同じ6ページでの適用

原稿・structure（必須文62項目）・スタイルYAMLは前回と同一。内容やページ数を変えず、次のように再設計した。

| ページ | 主役と配置 |
| --- | --- |
| 1 | 問いの表紙。大きな文章と網点円は役割に合うため維持 |
| 2 | 約30万km/sを最大にし、右に二原理、下辺に主張 |
| 3 | 地球系という条件のもと、2つの時計を上下の対応行で比較 |
| 4 | 大きな時空図。主張と条件は左側の余白へ |
| 5 | 上部の二説明から、下部の巨大な結論へ読む |
| 6 | 二要因が時計補正へ合流し、GPSにつながる全幅の関係図 |

2回生成、修正1回。初稿の全6PNGを見た後、2ページ目の単位に網点が重なる箇所と、説明の余分な空行を修正。最終2ページ目を再確認し、他5PNGは確認済み初稿とバイト一致。全6ページの同縮尺一覧でも主役の位置・面積・読む方向を確認。3・5ページの対応行は比較という意味のため残している。

## 検証と制約

- 原稿全6節をPPTXの発表者ノートXMLへ独立照合。全必須文を維持。
- review_deck: passed（成果物同一性とレビューの網羅性。自動美的評価ではない）。
- Skill quick_validate: valid。既存の設計ワークフロー14件pass、配布テスト7件pass / 1件skip。
- 画像生成・Web・別APIなし。網点は前回生成済み背景を再利用。
- LibreOfficeで確認。PowerPointアプリ自体は未確認。PPTXの編集環境にHiragino Sans/W9、Impact、Courier Newが必要。
- 同じ担当AIが修正し再制作した適用例であり、未知の題材での独立した有効性検証ではない。今後すべての単調な構図を防止できると保証しない。
