# v0.18.0：見出し・図表の強弱・説明の重複・前後のつながり

未公開の改善版。見出しを題目・問い・根拠のある要点から選び、既存communicationメモから実際の見出し・根拠を示す要素・強調箇所を参照できるようにした。古い自由記述と参照なしの設計は維持する。全見出しの結論化やページ数・順序の変更は強制しない。

design-checks.jsonにreading_outlineを加え、実際の見出し列と宣言した要点・原稿の根拠・画面の参照先・強調書式・前後の関係を並べる。意味・物語の品質を自動判定したり、原稿にない関係を生成したりしない。repeated_explanationsは、同じページの別要素と表に重なる長い説明のリテラルな反復を示す。表内の共通条件や短い役割名は警告しない。反復が必要なら理由を確認して保持し、自動削除はしない。

ネイティブの横棒・縦棒は、系列とカテゴリを明示して選んだ点の色を変えられる。PptxGenJS 4.0.1にない複数系列の個別点の色を、新規生成候補のネイティブXMLへ適用する。データ・順序・全値・軸・編集用ブックは変更しない。既存の利用者PPTXにはこの処理を適用しない。折れ線の個別点の強調は未対応。

PPTX検証は、表セルの文字色・太字・指定した塗り、グラフの系列色と個別点の色も照合する。値が同じでも強調が欠落・変更した場合を検出する。

既存の4ページ例では、全15表セルと全8値・0を保ち、共通条件を示す見出し、重複した脚注の整理、通常経路と例外の線の強さ、6月の2点の強調を実装した。原稿、スタイル、受入基準、旧PPTXは上書きしていない。話者ノートも読者向けの説明へ整理し、制作上の宣言を除いた。

内部の全自動検証は233件、失敗0、9件スキップ。新しい8件の編集検査と、4件の入力・ネイティブ出力・書式欠落の検証を含む。最終4PNGは実見した候補と同一であることを指紋で照合した。

新しい原稿とスタイルだけを渡した別担当は、代表2案から全2ページを制作し、communicationの要点と実在要素・強調箇所・前後の関係を結び付けた。全15表セル、6値と0、単位・架空の1日という範囲を保持した。別担当と改良担当が実画像を読んで原稿と照合し、レビューはpassed。個別点の色はこの独立制作では使わず、要点の大きな見出しで強調した。個別点の共通APIは4ページ例とネイティブ出力のテストで検証した。試験準備側の設定誤指定1件と制作補助の停止6件は解決し、内訳を記録した。

通常版・Windows用一式は共通Skill全72ファイルと最終ソースが同一。通常版ZIPのSkillだけを別フォルダーへ展開して再生成した全4PNGは、最終例とバイト同一。Windows用配布物の追加検査12件も通過したが、Windowsバイナリの実行ではない。

制作・最終レビュー・配布物の照合結果はartifacts/editorial-quality-20261122/へ保存した。Windows・Macのクライアント実機の追加確認は利用者の指示により後工程。公開・グローバル導入・コミット・pushは実施していない。
