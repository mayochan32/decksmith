# v0.14.0 制作手順と構図比較の改修

ローカルで作成した未公開の改修版。Gitタグ・push・GitHub Release公開・既存環境へのインストールは行っていない。

## 問題と変更

既存のWindows出力には、大きな単語と説明文を並べ、内容上の比較や関係を視覚的に示す工夫が弱いページがある。手順書には既に図解と見た目の確認を指示していたが、全ページのsceneを作った後で代表ページを抽出できる構成だった。構造検査や文字の収まりの確認だけでは、説明の伝わりやすさは保証できない。

新規制作・全体再設計では、原稿を整理した後、代表的な説明ページの異なる案を先に描画して比べ、採用方針を全体へ展開する。既存のdesign-planとcomposition/communicationメモを使い、新しい必須書式や採点表は追加しない。スタイル変更だけ・配置固定・テンプレート再現・小さな修正には、不要な構図変更を強制しない。

`workflow.py compare --board <新しいHTML>`で、PPTXとPNGの指紋を照合したA/B比較を保存できる。画像を埋め込んだ自己完結HTMLで、ネット接続は不要。既存ファイルは上書きしない。Windows PORTABLEランチャーも同じオプションを転送する。既存のcompare呼び出しは互換。

## 確認用の試作

提供済み相対性理論原稿の第2節・第6節を使用。同じ2ページの必須内容と元のスタイルYAMLでA/Bを作り、各PNGを目視した。

- 光速：Aの上下2行と、Bの共通値と二観測者の対応を比較。Bを採用。
- GPS：Bの要因・理論の対応表と、Aの二要因から補正へつながる関係を比較。Aを採用。

採用案2ページは`artifacts/quality-workflow-20261121/selected/output/design-proof.pptx`。比較HTMLは同作業フォルダーの`comparison.html`。これは2ページの抜粋試作で、元の6ページ全体を再制作したものではない。元の各節の説明は話者ノートへ保持している。

同じAIが制作・確認した試作であり、独立した読者テストやVSCodeでの再現性検証ではない。採用案は構図の判断例で、スタイル名から選ばれるプリセットとして配布物に入れない。
