## 限界

PowerPoint本体、Windows実機、新しいWindows PORTABLE ZIPは未検証。日本語フォントの代替と描画差は環境に依存する。

PDF/PPT入力、画像内や表・グラフ内部の文字列の直接書き換え、ネイティブ図表の内部書式の全面変更は未対応。マスターから継承する重要内容は元ページを視覚確認して引き継ぐ。内部スライドリンク・未対応AlternateContent・解決できないネイティブ接続関係は拒否する。

自動検査は、原資料の数値・保護語・構造・対応関係を検査する。文章の意味や図の解釈、見た目の品質を自動保証するものではない。
