# v0.19.0：手順図の読み順と線どうしの交差

未公開の改善版。主な手順をたどったときの上下の往復、例外・戻りの置き方、戻った後の再処理と再提出先を、既存の内容設計ガイドへ追加した。横一列や固定の箱を全資料へ強制せず、読み順に問題がある場合に配置案を比較する。

共通のdesign-checks.jsonへline_conflictsを追加。開いたパスと直線の中心線について、交差・途中の接触・見える区間の重なりを報告する。全パスの端点どうしの接続は許容し、後から描かれた不透明な長方形・ネイティブ表・グラフに隠れる部分を区別する。部分的に隠れた重なりは残る区間を報告する。回転は線の座標に反映するが、回転したパネル・画像の透明度・矢印先端・曲線の遮蔽や交差は未測定。関係を推測したり、線を自動統合・削除したりしない。

4ページ例の3ページ目を、上段の申込者→受付窓口→運営担当、下段左の不足時だけの差し戻し・追記・同じ窓口への再提出、下段右の二終点という配置へ改めた。原稿と独立した必須基準、5本の関係、全条件と終点を保持。残り3ページのPNGは旧版と同一。初回の接続指定の調整を1回、描画後の終点内の余白修正を1回行い、旧出力・記録は保持した。

新しい交差検査には9件のテストを追加した。全自動検証は242件、失敗0、9件スキップ。最終の図を実見して原稿と照合し、変えていない3ページの画像同一性と全4枚の一覧も確認した。レビューはpassed。

通常版・Windows用一式は共通Skill全73ファイルが最終ソースと同一。通常版ZIPのSkillだけで再生成した全4PNGも完成版とバイト同一。Windows用配布物の追加検査12件も通過したが、Windowsバイナリの実行ではない。記録はartifacts/flow-quality-20261122/へ保存した。Windows・Macのクライアント実機の追加確認は、利用者の指示により後工程。公開・グローバル導入・コミット・pushは実施していない。
