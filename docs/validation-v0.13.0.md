## 残る制約

PDFの図表は96dpiの画像レイヤーであり、編集可能な表・グラフ・元データには戻らない。画像内の書式変更やOCRは行わない。①②で取り込みの忠実性を満たせないPDFは未対応。物理寸法の非標準UserUnitも固定配置の対象外。

PDF入力用依存は任意の別環境に準備する。標準のPPTX経路には影響させない。Windows本体とPowerPointによるPDF入力の実機検証は今回行っていない。
