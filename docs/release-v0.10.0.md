# DeckSmith v0.10.0

小さな説明文がページ内に散らばり、図や主張との関係を追いにくくなる問題に対応しました。説明を意味のまとまりで配置する制作ガイドと、その効果を画面で確認するレビュー手順を追加しました。

## 主な変更

- 一つの主張を補う説明は本文としてまとめ、図固有の注意は図のそばに置くなど、説明と対象の関係がわかる配置を選びます。
- まとめて読む本文、図の各部分に添える注記、比較対象ごとの説明を、内容に合わせて使い分けます。全ページを同じ構成へ固定しません。
- 間隔を詰めるだけで済ませず、段落・小見出し・文字の強弱と、図の存在感・余白を一緒に確認します。
- ページごとの目的と使ったテクニックを説明するMarkdownの標準納品を継続します。

今回の変更は、制作するAIが読むガイドとレビュー手順です。描画エンジンの自動レイアウト機能を追加したものではありません。

## ダウンロード

- **decksmith-v0.10.0.zip**：通常版。Python／Node.js等の実行環境は別途必要です。
- **decksmith-v0.10.0-portable-win-x64.zip**：Windows x64用PORTABLE版。Python／Node.jsと描画用依存パッケージを同梱します。PNG・PDFの出力にはWindowsデスクトップ版PowerPointが必要です。
- **SHA256SUMS.txt**：上記2ファイルのSHA-256チェックサム。

両ZIPに制作開始用の `setting/decksmith.yaml` を同梱しています。通常版は `renderer: libreoffice`、PORTABLE版は `renderer: powerpoint` を設定済みです。リポジトリの `setting/decksmith.yaml` も保持しています。既存の設定を使っている場合は、別の場所へ展開して更新してください。
