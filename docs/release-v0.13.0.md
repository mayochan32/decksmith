# DeckSmith v0.13.0 — PDF入力

既存PDFをスタイル変換の3モードへ入力できるようにした。抽出文字を座標付きの編集可能な文字枠へ復元し、図表・背景は画像レイヤーとして保持する。出力はPPTX、必要ならPDFと原資料との比較画像を生成する。

- ①②は、通常の文字抽出可能PDFを原ページと表示照合してから適用する。取り込み後は既存の文章・座標保持検査を使う。
- ③は抽出文字・画像と元要素の対応を残し、文章・配置・ページ構成を再設計する。
- スキャン、縦書き、回転、注釈、透過文字、文字を隠す図形、入れ子Form、標準以外のUserUnit等は①②を拒否する。③では該当ページを参考画像として取り込む。OCRは自動実行しない。
- 原PDFの指紋、取り込み記録、取り込み確認、元PDFから直接描画した画像を最終レビューへ結び付ける。未確認結果を自動承認しない。

PDF入力には追加のローカルPython依存が必要。通常のPPTX入力・PDF出力には不要。Windows PORTABLEの基本ランタイムにはPDF入力用依存を含めていない。自動インストールや外部変換サービスへの切り替えは行わない。

図表を編集可能な元データへ戻す機能はなく、画像内の配色・背景・線は①②で直接変更しない。スタイルの適用範囲はレポートで明示する。フォント差やPDF固有の構造により忠実に復元できない場合は、条件を偽って合格にせず制約を示す。

通常版ZIPをローカルに作成。公開、push、タグ作成は行っていない。Windows実機でのPDF入力は未検証。[PDF取り込み手順](../skills/decksmith/references/pdf-input.md)と[検証記録](validation-v0.13.0.md)を参照。
