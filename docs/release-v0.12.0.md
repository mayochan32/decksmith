# DeckSmith v0.12.0 — 文章改善と全体再設計

既存PPTXのスタイル変換に、モード②「文章改善・配置固定」とモード③「文章・配置・ページ構成の再設計」を追加した。

## モード②

元PPTXの枠、位置、寸法、ページ構成、図表等を保持し、AIが指定した通常文字列を改善する。変更前の文字列との完全一致、runの重複変更禁止、数値トークンと保護語の保持を検査する。文章の変更前後と理由をレポートに保存し、最終レビューには意味・条件と枠内での収まりの確認を求める。

## モード③

元資料から独立した要素・文章・グラフ値・ノートの一覧を作り、再設計したsceneとの対応を全件記録する。文章改善、位置・寸法変更、ページの分割・統合・順序変更が可能。通常の描画エンジンとデザイン検査を使い、元と結果の全ページを比較する。

表・グラフ・グループは配置用rectを元のネイティブ要素に置き換えて保持する。実際に参照する画像、グラフ、埋め込みワークブック等を取り込み、依存データのバイト一致を検査する。表の行・列の寸法も新しい枠に合わせる。内部データと書式は保持し、画像化しない。

## 使い方

既存の`restyle_deck.py inspect/apply`とWindowsの`inspect-source` / `restyle`へ、`--mode 2`または`--mode 3`を追加する。内部の変更計画やsceneはAIが作成する。利用者が書く必要はない。既存ファイルの上書き拒否、連番生成、PDF出力、共通reviewを継続する。

PPTX入力に対応。PDF/PPT入力、画像内の文字や表・グラフ内部の文字の直接書き換えは未対応。③のネイティブ取り込みでは元の内部書式を保持する。マスターから継承した重要情報は元ページの視覚確認で引き継ぐ。古い内部スライドリンクや未対応のAlternateContentは黙って壊さず拒否する。

通常版ZIPをローカルに作成した。公開、push、タグ作成は行っていない。Windows実機とPowerPoint本体は今回未検証。[利用ガイド](../USER_GUIDE.md#25-既存pptxのスタイル変換3モード)と[検証記録](validation-v0.12.0.md)を参照。
