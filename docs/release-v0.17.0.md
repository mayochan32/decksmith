## 関係図の描画

connector要素で接続元・接続先を参照し、周囲の文字・図形を避ける直角の経路と条件ラベルを生成する。元の設計でノードを動かして再生成すると経路も更新する。原稿上の関係・条件はAIが明示し、処理が新しい関係や段階を推測することはない。

条件ラベルは幅が足りる水平区間を優先し、字面が線へ近づく揃え方を使う。明示されたalign/verticalと固定位置は保持する。経路とラベルの場所が確保できなければ、内容削除や文字縮小で隠さず設計の修正へ戻す。出力は編集可能なネイティブパス・矢印・文字。PowerPointでのノードのドラッグに自動追従する接続機能は含まない。

高さ・幅が少し異なる枠でも、向かい合う辺の中央付近で接続を揃え、不要な小さな段差を抑える。接続位置の比率を明示した場合は保持する。

通常のpathにもstart_arrow/end_arrowを追加し、矢印を別の三角形として手作業で合わせずに表現できるようにした。

## 描画前の手がかりと構造の照合

本文・ラベル・ネイティブ表の全セルを対象に、Unicode字幅と文字サイズから行数・必要高さを推定する。一字だけの自動折り返し、枠の収まり、開いた線と推定字面の交差をwarningへ記録する。線の上の不透明なラベル枠に隠れる場合を区別する。connectorのラベルは字面と線の距離も調べる。

推定は書体のシェーピングや実測字形ではなく、回転した字面・グラフ内の文字も対象外。ゼロ警告を見た目の合格と扱わず、全PNGの確認と原稿照合を維持する。処理は本文・文字サイズ・配置を自動的に変更しない。

PPTX構造検証では、パスの全頂点・閉じ方・矢印の端に加え、明示した文字の水平・垂直揃えも照合する。
