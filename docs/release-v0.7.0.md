# DeckSmith v0.7.0

## 文字・文章量の5段階指定

decksmith.yamlに任意のtext.amountを追加しました。

```yaml
text:
  amount: normal
```

- minimal：とても少ない。大きなキーワード・短いメッセージ中心。
- less：少なめ。要点と短い補足。
- normal：普通。要点に必要な説明を添える（既定）。
- more：多め。根拠・具体例・補足を載せる。
- dense：とても多い。配布して読める詳しさを、見出し・段組みなどで整理する。

text全体もamountも省略可能です。既存の設定は変更せず使用でき、省略時はnormalになります。画像量とは独立した設定です。

プロンプトの「文字量はとても少なく」などもAIが解釈します。brief.mdのページ別指定を全体設定より優先し、表示する文章と話者ノートを設計段階で振り分けます。画面掲載必須の文章・数値・条件は勝手に削除・ノート移動しません。文字数の固定上限ではなくAIの制作方針であり、根拠のない水増しや読めない文字サイズでの詰め込みを避けます。
