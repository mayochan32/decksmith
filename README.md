# DeckSmith

**style.yamlで、作りたいPowerPointのデザイン・表現形式を指定する。**
DeckSmithは、スタイルYAMLをAIが解釈して、内容に合わせた編集可能なPowerPointを作るツールです。配色だけでなく、書体、文字の大小、構図、画像の扱い、質感まで指定できます。

用意されたテンプレートやプリセットから選ぶ方式ではありません。同じ原稿でも、style.yamlを変えることで別の表現へ再設計できます。実現できない指定は、黙って無視せず制約を説明します。

**スタイルYAMLの作り方は、[こちらのQiita記事](https://qiita.com/mayochan32/items/18323a3f5201d08e8afc)を参照してください。** 作成したYAMLを `style.yaml` として渡せます。NotebookLMの利用は必須ではありません。

## はじめる

配布ZIPは次の2種類です。AIツール別にダウンロードし直す必要はありません。

- `decksmith-vX.Y.Z.zip`：通常版。Codex・Claude Code・GitHub Copilot・Gemini CLI用の共通Skill、登録情報、導入処理を同梱。実行環境は別途準備します。
- `decksmith-vX.Y.Z-portable-win-x64.zip`：Windows用PORTABLE版。共通SkillとPython・Node.js等を同梱します。

通常版には各ツールの登録情報が共存しますが、利用しないAIツールのインストールや契約は不要です。Gemini CLIでの実利用は未検証です。

作業フォルダーは、原稿・設定・参考資料を入れる `setting/` と、生成結果を保存する `output/` を同列に分けます。`setting/decksmith.yaml` の出力先は既定で `../output` です。

- 手順全体：[利用ガイド](USER_GUIDE.md)
- Windowsで環境準備を減らしたい方：[PORTABLE版ガイド](PORTABLE_GUIDE.md)
- 入手先：[GitHub Releases](https://github.com/mayochan32/decksmith/releases)（各リリースに実際に添付された配布物を確認してください）

## Windows PORTABLE版 — ZIPを展開して使える正式な配布方式

**Python・Node.js・npm・描画ライブラリの個別インストールは不要です。** Windows x64用のPORTABLE版には必要な実行環境を同梱し、`decksmith.cmd` から起動します。LibreOffice・Popplerも不要です。

ただし、すべてのソフトが不要という意味ではありません。

- AIエージェント（例：VS CodeのCodex／Claude Code）と、その利用契約・認証は別途必要です。
- プレビュー・PDFを作る場合は、インストール・認証済みのWindowsデスクトップ版PowerPointが必要です。
- PowerPointなしでもPPTXだけ生成できます。その場合は「見た目未確認」として出力します。
- フォントはPCにあるものを利用します。

Macや自分のPython／Node.jsを使う環境には、通常版を用意しています。PORTABLE版はWindows x64専用です。

## 3つのファイルで依頼する

| ファイル | 指定するもの |
| --- | --- |
| `brief.md` | 何を伝えるか：題材・対象読者・目的・ページ構成・必須内容 |
| `style.yaml` | どう見せるか：配色・書体・構図・画像表現など |
| `decksmith.yaml` | どう生成するか：サイズ・言語・文字量・画像方針・通信制限・出力方式 |

原稿や制作条件はプロンプトでも指定できます。全設定入りの雛形を用意しているため、`decksmith.yaml` を1から書く必要はありません。内部の構成・配置ファイルはAIが作成します。

## 主な機能

- **任意のスタイルYAMLを解釈**：スタイル名から固定構図を選ぶのではなく、資料ごとに設計します。
- **サイズと言語**：既定は横長16:9・1920×1080px。縦長・正方形・任意寸法にも対応。`日本語` や `english` などの言語名も指定できます。
- **文字量は5段階**：minimal／less／normal／more／dense。口頭説明は話者ノートへ整理し、必須の数値や条件を保持します。
- **画像の量・種類・色調**：提供画像の活用と、利用環境に備わった画像生成に対応。ページ別の指定を優先できます。
- **編集可能なPPTX**：文字・数値・基本図形・パスは編集可能。写真や生成画像そのものは画像として配置します。
- **確認と修正**：プレビューを確認して再生成し、既存の出力は上書きしません。PDFも任意で出力できます。

画像生成できない場合は、**画像なしで再配置するか、画像位置の四角に生成プロンプトを記載するか**を人間に確認します。後者は「画像差し替え待ち」として納品します。

## 通信と承認

`privacy.mode` の既定は `restricted`。利用中のAIサービスの組み込み機能とローカル処理を使います。**Web検索・外部サービスはnormalを含む全モードで人間の事前承認が必要**です。restrictedでは制限の例外であることも明示します。初回セットアップの取得も、AIが行う場合は事前に確認します。

開始時に通信方針と画像生成の利用可否を案内します。原稿・画像・プレビューは利用中のAIサービスへ送信され得ます。これはAIの操作ルールであり、OSの同期や拡張の通信を遮断する機能ではありません。

## 利用環境と対応範囲

Codex、Claude Code、GitHub Copilot（VS CodeのAgentモード）、Gemini CLI向けに共通のSkillと描画エンジンを用意しています。Copilotは `.github/skills/decksmith/` へ登録します。Gemini CLIはターミナルでの実行を想定し、実利用は未検証のまま提供対象に残しています。DeckSmith自体は独立したVS Code拡張ではなく、ブラウザー版チャットへの直接導入も対象外です。AIや画像生成機能が異なれば、同じ指定でも結果は異なります。

通常版はPython 3.9+、Node.js 18+と描画ライブラリを用意します。プレビューはLibreOffice＋Poppler、またはWindowsのPowerPointを使用。PPTXのみなら変換ソフトは不要です。YAMLライブラリは同梱しています。

専用のネイティブ表・グラフ要素や複雑なマスクなどは未対応です。フォントはPPTXへ埋め込まれないため、閲覧先で改行や見た目が変わる場合があります。

## バージョン

`vx.y.z`（メジャー・マイナー・bugfix）形式です。配布物直下の `VERSION`、実行開始時の表示、生成記録で確認できます。PORTABLE版は `decksmith.cmd --version` でも確認できます。

この文書は現在のソースの仕様です。正式な配布方式の採用と、更新版ZIPの公開は別です。公開済み配布物の内容は、リリースの説明とVERSIONを確認してください。
