# 文字と図形のバランス

重なりは表現手段。共通基盤、交差、包含などを示す必要があれば残す。直す対象は、意図に合わない文字の大きさ・位置、余白、線や塗りの強さ、同等要素の不揃い。

## 設計する順序

1. 同格の要素と、図形に属する文字を特定する。強調された一つの塗りや意図的な非対称を、機械的に均一化しない。
2. ラベルの長さ、読みやすい文字サイズ、必要な余白から図形寸法を一緒に決める。空いた箱に合わせて文字だけを縮小しない。長いラベルは幅・改行・構成を再検討する。
3. 同格の文字サイズとウェイト、図形寸法、間隔を比較する。中央配置だけが正解ではない。左揃え、上寄せなどは構成意図に合わせる。複数の領域全体にかかる共通基盤の帯など、左右対称な図形の全体を短い語で名付ける場合は中央揃えを優先する。一方、行見出しとして右側の説明へつなぐ場合や、長文の読み始めを揃える場合は左揃えが適する。図形の横長さだけで決めない。
4. 重なる帯は厚さ・塗り・線幅を調整し、領域名や他の主役を圧倒していないか確認する。下地の線が文字を横切るなら描画順序と安全域を直す。
5. 実際のPNGで文字の見かけの中心、改行、曲線内側の余白、全体の重心を確認する。文字枠の中心と字面の中心は同じとは限らない。幅いっぱいの文字枠が図形の中央にあっても、alignがleftなら短い文字は左へ偏る。枠の座標に加え、枠内の揃え方と実際の字面を確認する。必要なら文字枠を光学的に補正し、その理由を残す。

## 主張の強さを保つ

余白・行間・整列を直す前に、このページで最も伝えたい内容を一つ特定する。その内容の文字の太さ・大きさ・対比を基準に、補助説明を従属させる。整ったが弱い見出しへ置き換えない。太い表現が必要なら実在する太いウェイトを指定し、通常のbold指定やフォント名だけで太さを判断しない。元の表現意図と描画された字面を比較する。すべての主張を極太にする規則ではなく、その内容と参考の表現に必要な強さを保持する。

## 行間と情報のまとまり

- 一つの主張を複数行にする場合は、原則として一つの文字枠で組む。行ごとの演出が必要な場合だけ分ける。各行を別のパーツのように等間隔配置しない。
- 見出し内部の行間と、見出しから次の情報までの余白を区別する。関連する行は近づけ、別のまとまりは離す。固定の行間倍率を万能な正解にせず、書体・太さ・句読点を含む実際の字面で確認する。
- パーツを置く前に「主張」「根拠・補足」「次の行動」などの情報群を決める。群内の距離は群間より小さくし、共有する左端・上端・本文の開始位置を少数の基準線に揃える。全パーツへ別々の枠を足すだけで整理したことにしない。
- バッジやラベルは所属する説明のそばに置き、大見出しの最終行と明確に離す。意図した図形同士の重なりと、字面を隠す・別の情報群へ食い込む衝突を区別する。文字枠だけでなく、描画後の字面から余白を確認する。
- 短いバッジは意図しない改行を避ける。文字を縮める前に必要幅を確保する。本文も語や意味の切れ目で改行を調整し、短い語だけが次行へ残ってパーツの高さを乱していないかを見る。

## 軸見出しと成果の領域

- 行列図やグラフでは、軸見出し・行列ラベル・凡例の領域を先に取り、残りを本体へ割り当てる。図を敷き詰めた後でラベルを隙間に押し込まない。回転した文字は回転後の見える範囲で確認し、読みにくければ対応関係を保って水平配置する。
- 軸を読むために必要な文字を、セル・帯・カードなど別の要素で隠さない。意図した図形の交差とは別に、軸見出しの字面全体と周囲の空きを検査する。
- 成果・結論の枠では、OUTCOMESなどの分類名より、成果そのものに視線が向くようにする。短い成果文に大きな箱を先に与えない。必要な文字サイズと内側の余白から箱の高さを決め、空きすぎるなら文字の拡大と箱の縮小を検討する。
- ページの主張、重要な成果、図の項目名、補足説明を役割別に扱う。文字サイズが全部近くなった場合は、何を先に読ませるかに立ち戻って差を付ける。同格の成果同士の大きさは揃える。固定の比率を全資料へ押し付けず、描画後の読み順で判断する。

## 任意の測定宣言

AIがdesign-plan.yamlの各slides項目にbalance_groupsを記録できる。同じ扱いにする理由がある要素だけを明示する。全図形を自動分類せず、意図を決めてから許容範囲を書く。測定値に合わせて限界を緩め、警告を消す作業にしない。

```yaml
balance_groups:
  - id: capabilities
    reason: 三つの能力は同格。最初の白い塗りだけは強調として保持
    members:
      - {shape: capability-1, label: label-1}
      - {shape: capability-2, label: label-2}
      - {shape: capability-3, label: label-3}
    checks:
      font_size: {max_spread: 0}
      shape_height: {max_spread: 0}
      font_height_ratio: {min: 0.22, max: 0.34}
      text_box_center_y: {min: 0.46, max: 0.54}
      gap_x: {max_spread: 2}
```

上の数値は例であり既定値ではない。フォントや寸法、資料の役割ごとに決める。各checksはmin・max・max_spreadの少なくとも一つを持つ。

- font_size、shape_width、shape_height、gap_x、gap_yは96DPIのpx。文字サイズはrunを含む最大有効サイズ。間隔は該当軸上で図形を並べて測定する。負の間隔は重なりを表し、禁止しない。
- font_height_ratioは文字サイズ÷図形高さ。字面の占有率ではない。
- text_box_center_x/yは図形の左端／上端を0、右端／下端を1とした文字枠中心。
- padding_left/right/top/bottomは図形の外接矩形に対する文字枠余白の比率。角丸や楕円の内側、実際の字面の余白は画像で確認する。
- shapeはshape/path、labelはtextの実在IDを指定。回転があるグループはunmeasuredとして視覚確認を促す。文字の折返しや字面、線幅・塗りの視覚的重量は測定対象外。

design-checks.jsonへ値と範囲を保存し、逸脱はレビュー警告にする。美しさの点数や自動合格ではない。修正または意図した例外を実画像で判断し、既存のwarning_resolutionsに根拠を記録する。宣言のない旧資料の生成方法は変わらない。
